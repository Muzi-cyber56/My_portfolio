# Objectives
- Organize investigations into owner-scoped cases with a stable case number, scope notes, status and priority.
- Validate phone, email, username, domain, IP and CNIC inputs without fabricating personal information.
- Preserve uploaded evidence as original bytes, calculate SHA-256 and detect later modification.
- Extract image properties and available EXIF metadata; support local OCR when Tesseract is configured.
- Show case membership and repeated input hashes in a relationship graph without asserting unverified identity links.
- Generate downloadable PDFs containing findings, sources and freshly verified evidence hashes.
- Provide a consistent black, blue and white Flutter UI on mobile and web.
